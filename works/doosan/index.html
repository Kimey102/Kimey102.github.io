01 · 시즌 대시보드

매일 08:30에 KBO 순위, 득실, 최근 10경기, 상대 전적, 일정을 모아 다시 만듭니다. 가을야구 확률은 피타고리안 승률과 실제 성적을 섞은 전력값으로 남은 경기를 10만 번 모의 시행해 계산합니다.

02 · 경기 전과 경기 후 리포트

경기 전에는 선발과 라인업을 반영해 승률을 예측하고, 경기가 끝나면 그 예측이 어떻게 맞고 틀렸는지 다시 봅니다. 샘플은 10월 6일 사직 롯데전으로, 두산 66%를 예측했고 3 : 1로 이겼습니다.

03 · 텔레그램 알림

경기 전에는 선발과 라인업에 예상 승률과 사전 리포트를, 경기 후에는 박스스코어에 사후 리포트를 붙여 보냅니다. 봇은 승률을 직접 계산하지 않고 사람이 분석한 값을 배달만 합니다.

만들면서 지킨 것

숫자가 매일 바뀌는 도구라, 틀린 값을 그럴듯하게 보여 주지 않는 쪽을 먼저 챙겼습니다.

  • 모르면 비워 둡니다

    수집에 실패한 항목은 빈칸으로 두고, 값을 추정해 채우지 않습니다.

  • 계산과 배달을 나눕니다

    예측은 사람이 분석해 노션에 정리하고, 봇은 그 값을 정해진 시각에 보내기만 합니다.

  • 사람 손 없이 돕니다

    GitHub Actions가 매일 아침과 경기 전후에 스스로 실행되고, 결과는 GitHub Pages에 바로 올라갑니다.
