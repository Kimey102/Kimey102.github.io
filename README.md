# kimey102.github.io — 밍지 · 작업 모음

밍지의 개인 포트폴리오 사이트입니다. GitHub Pages(main 브랜치 루트)로 https://kimey102.github.io 에 게시됩니다.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 첫 화면. 소개, 작업 세 개(도서관·두산 베어스·캠핑장 알림), 일하는 방식 요약 |
| `practice/index.html` | 'Claude와 일하는 방식' 상세 페이지(연구용역 실무 원칙·과업 순서·MCP 도구·기기 환경) |
| `library/template.html` | 알렉산드리아 도서관 공개본의 원본. 데이터 자리(`/*__BOOKS__*/` 등)가 비어 있다 |
| `library/index.html` | 매일 자동으로 다시 만들어지는 도서관 공개본. 손으로 고치면 다음 갱신 때 덮어써진다 |
| `library/public.json` | 공개할 개념 카드·변곡점 목록, '생각 하나가 자란 길' 예시 카드, 공개 전에 바꿔 쓸 문구 |
| `scripts/build_library.py` | 노션 세 데이터베이스를 읽어 `library/index.html`과 첫 화면 숫자를 다시 만드는 스크립트 |
| `.github/workflows/update-library.yml` | 매일 05:17 KST에 위 스크립트를 실행하고, 기록이 바뀐 날만 커밋 |

## 자동 갱신

- 노션 연결 '도서관 공개본'(API 토큰 방식, 콘텐츠 읽기만, 접근 범위는 '독서 & 사유' 페이지)의 토큰을 저장소 Secrets의 `NOTION_TOKEN`에 넣어 두었습니다.
- Actions 탭의 update-library에서 Run workflow를 누르면 바로 갱신됩니다.
- 수집이 하나라도 실패하면 파일을 바꾸지 않고 실패로 끝나므로, 사이트는 직전 상태로 남습니다.
- 날짜만 바뀌고 기록이 같으면 커밋하지 않습니다.

## 공개 원칙

- 서가(나의 책장)는 전부 싣습니다.
- 개념 카드와 변곡점은 `library/public.json`에 있는 것만 싣습니다. 노션에 새로 생긴 것은 이 목록에 넣기 전까지 공개되지 않습니다.
- `replace` 규칙으로 개인을 특정할 수 있는 표현을 공개 전에 바꿔 씁니다(노션 원문은 그대로 둡니다).
- 머리말과 첫 화면의 숫자는 공개 범위와 상관없이 전체 개수를 씁니다.
- 노션 링크는 방문자가 열 수 없으므로 화면에서 눌리지 않게 처리합니다.
- 본명은 쓰지 않고 '밍지'로만 표기합니다.

## 고칠 때 주의

- 도서관 화면을 바꿀 때는 `library/template.html`을 고쳐야 갱신 뒤에도 유지됩니다. 바로 반영해 보려면 `library/index.html`에도 같은 수정을 넣거나 workflow를 수동 실행합니다.
- 첫 화면의 숫자와 날짜는 `<!--n:books-->` 같은 표식 사이 값을 스크립트가 바꿉니다. 표식을 지우면 갱신이 실패합니다.
- 두산 베어스 대시보드와 분석 리포트 링크는 별도 저장소 `KBO_Doosan-Bears`의 GitHub Pages(`/KBO_Doosan-Bears/`)를 가리킵니다.
